# 🚗 ADAS – Traffic Sign Recognition & Lane Detection

## 📌 Overview
An AI-based Advanced Driver Assistance System (ADAS) prototype using Deep Learning and Computer Vision.

## ✨ Features
- Traffic sign recognition (43 classes).
- Lane detection using OpenCV.
- CLAHE image enhancement.
- MobileNetV2 and ResNet18 model comparison.
- Prediction confidence and FPS display.
- ADAS visual overlay.

## 🛠️ Technologies
- Python
- PyTorch & Torchvision
- OpenCV
- NumPy & Pandas
- Matplotlib & Seaborn
- Scikit-learn

## 📊 Dataset
- GTSRB (German Traffic Sign Recognition Benchmark).
- 43 traffic sign classes.
- Synthetic fallback dataset if download fails.

## ⚙️ How to Run
1. Open `adas.ipynb` in Google Colab.
2. Enable GPU (if available).
3. Run all cells.
4. View predictions, evaluation graphs and ADAS output.

## 📁 Main File
- `Untitled3.ipynb` – Complete project implementation.
